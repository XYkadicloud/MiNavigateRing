# 真机验证清单（Google 地图 / 所有 GMS 手机）

本版本把地图源换成 Google 地图后，手机端的**解析器**和**通知监听**是新写的，尚未在真机上验证过。下面这份清单用于在任意带 GMS 的安卓手机上做一轮最小验证，重点覆盖：**非小米机型、不同屏幕密度、中英文界面、转向图标哈希**。

> 前提：手机已装**小米运动健康**并配对**小米手环 9 NFC**，手环已装本项目的 RPK，手机已装本项目的 APK（包名 `com.mapring.probe`，与原版 `com.minavigatering.probe` 可同时安装）。

## 0. 准备

- [ ] 手机系统带 Google 服务（GMS），能正常登录/使用 Google 地图。
- [ ] Google 地图可正常导航（步行 / 骑行至少一种）。
- [ ] 本应用已授予**通知读取**权限。
- [ ] 本应用与小米运动健康都设为：允许自启动 / 后台运行、省电“无限制”、允许忽略电池优化（各厂商叫法不同）。
- [ ] 记录设备信息：机型、Android 版本、Google 地图版本、屏幕 DPI、系统语言。

## 1. 基础链路（与地图无关，应当直接通过）

- [ ] 打开应用 → “开启导航桥”，前台服务出现。
- [ ] 手环上打开“地图环”页面，手机主页显示“等待 Google 地图导航”。
- [ ] 手机发送测试状态后，手环显示对应箭头/距离，手机收到回执。
- [ ] 手环熄屏、手机锁屏后，仍能更新（至少 5 分钟）。

## 2. Google 地图解析（本版本的重点）

逐项在 Google 地图里走到对应动作，观察手环：

| 动作 | 手环应显示 | 通过 |
|---|---|---|
| 直行 / 继续 | 直行箭头 + 距离 | [ ] |
| 左转 | 左转箭头 | [ ] |
| 右转 | 右转箭头 | [ ] |
| 左前方 / 右前方（缓弯） | 对应箭头 | [ ] |
| 靠左 / 靠右（分岔） | 对应箭头 | [ ] |
| 进入环岛 | 环岛箭头 | [ ] |
| 驶出环岛（第 N 个出口） | 环岛出口 + 出口号 | [ ] |
| 掉头 | 掉头箭头 | [ ] |
| 到达 | 到达 | [ ] |

- [ ] 距离数字与 Google 地图基本一致（米 / 公里，英文界面 m / km / mi / ft）。
- [ ] 路名在 Google 地图给出时能显示（中文“中山路”、英文“Main St”）。
- [ ] **读不出方向时**（例如只有“正在为您导航”这类通用通知）手环显示“暂无导航”，手机主页写明原因，**绝不显示猜测方向**。
- [ ] 导航结束后手环显示“暂无导航”，手机说明“已结束”。

## 3. 转向图标哈希专项（不同 DPI / 主题）

- [ ] 在**默认主题**下，上面第 2 节的方向全部正确。
- [ ] 切到**深色主题**再走一遍：方向是否仍正确？若变差，记录哪些动作读不出。
- [ ] 若方向大面积读不出（手环长期“暂无导航”但地图在导航），按 [icon-calibration.md](icon-calibration.md) 重新标定图标哈希表。
- [ ] 换一台不同 DPI 的手机重复本节。

## 4. 语言

- [ ] 系统语言为**中文**：距离/路名/方向全部正确。
- [ ] 系统语言为**英文**：距离/路名/方向全部正确（英文方向词靠文字兜底，图标哈希与语言无关）。
- [ ] （可选）其他语言：至少确认不会误判方向；读不出时显示“暂无导航”。

## 5. 后台与恢复

- [ ] 手机锁屏 30 分钟，导航持续更新。
- [ ] 手机重启后，导航桥自动恢复、通知监听自动重绑。
- [ ] 应用进程被划掉后，重新导航能自动拉起手环页。

## 6. 非小米机型特别注意

- [ ] 三星：确认“从不清除 / 不受限制”已设置，否则息屏后被冻结。
- [ ] Pixel：确认“不受限制”。
- [ ] 其他 OEM：确认没有额外的“后台限制 / 深度睡眠”把应用杀掉。
- [ ] 若息屏后不更新，先查是否被系统冻结，再查通知监听是否被断（主页会提示“通知读取未连接”）。
